# Security policy

Use the latest GitHub release. Older builds may not receive fixes.

Buffer stores clipboard history on the Mac. It requests Accessibility permission only to simulate the paste shortcut into the previously focused app. The app checks GitHub Releases for updates; it does not upload clipboard text or screenshots.

Please report vulnerabilities through GitHub's private vulnerability reporting for this repository when available. Avoid posting clipboard samples, personal data, or unpatched exploit details in a public issue.
